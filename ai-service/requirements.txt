# ML

# scikit-learn is PINNED, not ranged. The six artifacts in models/agents/*.pkl
# were fitted on 1.7.1, and a pickle stores the class layout of the sklearn
# version that produced it. Loading them under a different minor release can
# either fail outright or, worse, reconstruct an estimator whose internals no
# longer line up. The quality agent is a live example: a 1.7.1-fitted
# SimpleImputer reconstructed under 1.8.0 has no `_fill_dtype`, which 1.8.0's
# transform reads — so it deserialises cleanly and then raises on every
# request.
#
# The loader verifies each artifact's SHA-256 before it deserialises, and warns
# when an artifact's recorded training scikit-learn differs from the running
# one. The pin and the warning are two independent guards: the pin is what you
# are meant to install, the warning is what tells you when you did not. Do not
# "fix" the warning by editing the recorded version — the recorded version is
# the artifact's provenance, not a setting.
#
# `python agents/generate_digests.py --check` verifies the artifacts still match
# their digests and prints the training version alongside.
#
# If you change this, re-train via agents/legacy/ and re-run
# `python agents/generate_digests.py --trained-on <the version you trained on>`.
